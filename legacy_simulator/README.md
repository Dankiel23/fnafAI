# Legacy Browser Simulator

This folder contains the original non-RL browser simulator and its frontend assets.

It was moved out of the repository root so the top-level project structure stays focused on the Python AI training environment in `fnaf_gymnasium/`.

Contents include:

- TypeScript source in `src/`
- compiled web output
- frontend config files
- browser-only assets such as images, audio, and icons

Use this folder as historical reference material if you need to compare the Python simulator against the original browser implementation.
